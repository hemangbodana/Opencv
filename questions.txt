# 1. Most likely practical exam questions

## Question 1: Restricted zone intrusion detection

Very likely

A restricted area on a factory floor must be monitored. Raise an alert when a person enters the area and remains there for at least 10 consecutive detections.

Requirements:

- Select a polygonal restricted area on the first frame.
- Detect only people using YOLO.
- Use the bottom-center of each bounding box to determine whether the person is inside the polygon.
- Change the polygon color from green to red when an alert is active.
- Save the output video and alert timestamps to a CSV file.

What it tests: Your current assignment almost exactly.

## Question 2: PPE detection — helmet or no helmet

High priority

A construction site requires workers to wear helmets. Detect workers and raise an alert if a worker is not wearing a helmet.

Requirements:

- Run an object detection model on video frames.
- Detect `person` and `helmet` classes.
- Determine whether a helmet is associated with each person.
- Draw green boxes for compliant workers and red boxes for workers without helmets.
- Save the annotated video and count the violations.

What it tests: Multiple classes, bounding-box overlap, conditional alerts and counting.

Note: You need a model trained to detect helmets; a standard YOLOv8 COCO model does not provide a dedicated helmet class.

## Question 3: Vehicle entry into a restricted area

A parking lot has a restricted polygon. Raise an alert when a car or motorcycle enters it.

Requirements:

- Select the restricted area using mouse clicks.
- Detect cars and motorcycles.
- Use the bottom-center of each vehicle box as its position.
- Require three consecutive positive detections before raising an alert.
- Save the video and violation log.

What it tests: Class filtering, polygon testing and temporal confirmation.

## Question 4: People counting at an entrance

Count how many people cross a virtual line at a building entrance.

Requirements:

- Detect people in every fifth frame.
- Draw a horizontal counting line.
- Count a person when their feet cross the line in a specified direction.
- Avoid counting the same person repeatedly.
- Display the total count on the video.

What it tests: Line-crossing geometry, object tracking, frame skipping and counters.

## Question 5: Loitering detection

Detect people who remain within a designated area for at least five seconds.

Requirements:

- Select a polygonal area.
- Detect people and calculate their feet positions.
- Track each person across frames.
- Start a timer when a person enters the area.
- Raise an alert if the person remains there for five seconds.
- Reset the timer when the person leaves.

What it tests: Tracking, timestamps, state management and duration calculations.

## Question 6: Speed up object detection on a large video

A video is 1920 × 1080 at 60 FPS. Process it efficiently while preserving the original output resolution.

Requirements:

- Resize frames before inference.
- Run inference on every third frame.
- Scale bounding boxes back to the original frame.
- Draw detections on all output frames.
- Save the annotated video at the original FPS and resolution.

What it tests: Resizing, coordinate scaling, frame skipping and `VideoWriter`.

# 3. Important practical coding patterns to memorize

These are the OpenCV and NumPy operations most likely to appear in variations of your assignment.

| Task | Function or technique |
| --- | --- |
| Read video | `cv2.VideoCapture()` |
| Read a frame | `cap.read()` |
| Resize a frame | `cv2.resize()` |
| Load ONNX model | `cv2.dnn.readNetFromONNX()` |
| Prepare model input | `cv2.dnn.blobFromImage()` |
| Run inference | `net.forward()` |
| Remove duplicate detections | `cv2.dnn.NMSBoxes()` |
| Draw a bounding box | `cv2.rectangle()` |
| Draw a polygon | `cv2.polylines()` |
| Check if a point is inside a polygon | `cv2.pointPolygonTest()` |
| Draw the person's feet position | `cv2.circle()` |
| Save a video | `cv2.VideoWriter()` |
| Save results | Python `csv` module |
| Convert frame number to seconds | `frame_idx / fps` |

## 4. Common examiner follow-up questions

Prepare to explain these without looking at your code.

1. Why do we use the bottom-center of the bounding box instead of its center?
2. Why is a polygon better than a rectangle for selecting an irregular danger zone?
3. What is the purpose of Non-Maximum Suppression (NMS)?
4. Why do we resize the frame before inference?
5. Why must bounding-box coordinates be scaled back after resizing?
6. What happens if we increase the confidence threshold from 0.5 to 0.8?
7. Why do we require consecutive detections before raising an alert?
8. How do you convert a frame number into seconds?
9. What is the difference between object detection and object tracking?
10. What happens if a worker leaves the zone for one sampled frame?
11. Why must the video writer be initialized with the correct output resolution and FPS?
12. How would you prevent two different workers from contributing to the same alert streak?
